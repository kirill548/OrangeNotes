# Orange Notes v0.1.1 — AI Onboarding & Quality Suite

**Дата:** 9 октября 2026 г. **Базовая версия:** v0.1.0.

Локальный ИИ-помощник получил понятную первую настройку, улучшенный поиск и безопасный потоковый транспорт. Формат заметок SQLite сохранён; перед обновлением рекомендуется сделать резервную копию через меню приложения.

## Что нового

### Мастер настройки ИИ

- При первом открытии помощника проверяется локальный Ollama и наличие qwen3:4b / qwen3-embedding:0.6b. Проверка не запускает сервер и ничего не скачивает.
- Можно выбрать папку распакованного AI-pack для своей ОС и архитектуры либо явно скачать недостающие модели через локальный API /api/pull — с прогрессом и отменой.
- Если Ollama не установлен, мастер показывает ссылку на официальный установщик. Для скачивания моделей нужны работающий Ollama, интернет и несколько ГБ свободного места.
- «Пока пользоваться поиском» сохраняет выбор. Поиск, подсказки и создание заметок доступны без модели; вернуться к настройке можно позднее.
- Отсутствие embedding-модели не блокирует готовый диалог. В настройках видны модель, транспорт NDJSON и задержка проверки соединения.
- Закрытие приложения во время установки отменяет запрос и ждёт завершения фонового потока.

### NDJSON и отзывчивый интерфейс

- Ollama stream=true принимается в фоновом потоке через QNetworkAccessManager/QNetworkReply.
- Отмена вызывает reply.abort; проверка флага выполняется таймером 10 мс. Это период проверки, а не гарантия мгновенного завершения сервера или освобождения GPU.
- Ответ показывается целиком после проверки полного JSON, цитат и ревизий источников. Частичные непроверенные токены не появляются в чате или истории.
- Генерация ограничена общим дедлайном 30 секунд, включая предварительную проверку модели; лимит ответа — 4 МиБ, строки NDJSON — 256 КиБ. Долгая установка моделей имеет отдельный бюджет.

### Поиск по заметкам

- Фрагменты по 500 символов перекрываются на 100, шаг — 400. Соседние фрагменты объединяются в контекст до 1300 символов, помогая сохранить короткие фразы на границах.
- Неизменённые фрагменты и embeddings не перестраиваются повторно; memory_index_state связывает индекс с версией заметки.
- Полный body передаётся из SQLite в Python один раз на заметку, без дублирования в каждой строке JOIN. Актуальность проверяется отдельно внутри SQLite.
- Буквальные совпадения имеют приоритет. Fuzzy-предложения и семантический fallback применяются при отсутствии буквальных результатов; похожие ID не выдаются за точные факты.

### Проверяемые ответы

- При отсутствии информации предусмотрен канонический отказ: «В ваших заметках нет информации об этом».
- Факты показываются дословными цитатами из доступных источников; проверяются ревизии и разделение личного/рабочего контекста, в том числе непосредственно перед показом в UI.
- Гипотезы о связях допустимы при явном запросе на сравнение/связь. Добавлена консервативная блокировка очевидных команд внутри заметок; это не доказательство защиты от любых prompt injection или галлюцинаций.

## Проверки

- Локальный полный прогон Windows: **443 теста — 440 PASS, 3 SKIP, 0 FAIL**, 56.387 с. Пропуски не считаются успешными проверками.
- Quality Suite: **60/60 синтетических сценариев**; precision=1.0, recall=1.0, refusal rate=100% на этом контрольном наборе.
- Настоящая Qwen3:4B через NDJSON: **10/10 строгих отказов** на вопросы без ответа в предоставленных заметках; p50=0.590 с, p95=3.176 с. Это небольшой повторяемый benchmark, не гарантия качества любых свободных ответов.
- Онбординг: 33 сервисные/UI/интеграционные проверки. Протокол загрузки и отмена проверены на локальном тестовом HTTP-сервере; реальные гигабайтные модели в тестах не скачивались.
- Обнаружение обеих уже установленных моделей проверено на настоящем локальном Ollama. Новые результаты CI для релизного коммита указаны по ссылке ниже.

## Установка и ограничения

Основные .exe/.app/.deb и другие пакеты **не содержат гигабайтные модели**. ИИ подключается через встроенный мастер при первом открытии помощника. Заметки остаются на компьютере, аккаунт и API-ключ не требуются.

**Сборки без цифровой подписи (Unsigned).** Windows SmartScreen и macOS Gatekeeper могут показать предупреждение. Проверяйте источник загрузки и SHA-256 по SHA256SUMS.txt. Хеш подтверждает целостность скачанного файла, но не заменяет подпись издателя. Не отключайте защиту ОС глобально.

- **Windows:** распакуйте весь архив и запускайте OrangeNotes.exe вместе с соседними файлами. Если SmartScreen показывает «Windows защитила ваш компьютер», только после проверки источника выберите «Подробнее» → «Выполнить в любом случае». Если корпоративная политика запрещает запуск или этой кнопки нет, обратитесь к администратору; не обходите политику.
- **macOS:** выбирайте архив своей архитектуры, распакуйте .app и перенесите в Applications. После попытки запуска доверенного приложения используйте «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть», если эта возможность доступна. Подтвердите только это приложение. Developer ID и нотариальное подтверждение Apple пока отсутствуют. Если macOS сообщает о вредоносном или повреждённом приложении, остановитесь и проверьте загрузку; не удаляйте quarantine рекурсивно. Разрешите уведомления при запросе и проверьте их в настройках ОС.
- **Linux .deb (Debian/Ubuntu x64):** `sudo apt install ./OrangeNotes-Linux-x64.deb`. Администратор нужен для установки пакета, сама программа и её фоновая служба работают от обычного пользователя.
- **Linux AppImage:** разрешите выполнение скачанного файла (`chmod +x OrangeNotes-*.AppImage`) и запустите его из пользовательской сессии.
- **Linux Flatpak:** нужен установленный Flatpak и Flathub. Добавьте Flathub для пользователя: `flatpak remote-add --user --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo`. Затем `flatpak install --user ./OrangeNotes-Linux-x86_64.flatpak` (используйте фактическое имя скачанного файла) и `flatpak run org.orangenotes.OrangeNotes`.

Архив исходников включён отдельно. Пользовательские базы, настройки, модели и сертификаты в дистрибутив не включены. Перед обновлением сделайте резервную копию базы через меню приложения.

Сборки рассчитаны на Windows x64, Linux x64, macOS Intel и Apple Silicon в поддерживаемых средах. Совместимость с любыми ОС и 32-битными устройствами не заявляется. Flatpak напоминает в активной сессии приложения; постоянная внешняя служба не устанавливается.
