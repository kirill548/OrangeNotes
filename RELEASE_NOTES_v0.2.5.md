# Orange Notes v0.2.5

- **Android и iOS.** Последние правки сохраняются даже при быстром выходе из заметки, когда таймер автосохранения ещё не сработал.
- **Настольное приложение.** При переходе по ссылке на другую заметку можно сохранить изменения расписания или остаться в редакторе. После архивирования приложение открывает оставшуюся заметку, если она есть. Предупреждение о слишком большой заметке появляется при её открытии вручную.
- **Экспорт и резервные копии.** В качестве файла назначения нельзя выбрать рабочую базу или её служебный файл. При восстановлении приложение проверяет, свободна ли база. Если при экспорте произошла ошибка записи, прежний файл сохраняется.
- **Windows.** Проверка обновлений доступна и после запуска из уведомления. Устаревшие временные копии установщика удаляются при проверке обновлений.

На Windows выберите «…» → «Проверить обновления» или запустите установщик в прежней папке.
