# Orange Notes v0.2.3

## Обновление Windows

- Orange Notes проверяет наличие новой версии при запуске. Когда обновление доступно, внизу окна появляется кнопка «Обновление». Запустить проверку вручную можно через «…» → «Проверить обновления».
- Установленная версия скачивает официальный установщик из GitHub Releases и проверяет его SHA-256 перед запуском. Мастер сохраняет папку установки и закрывает работающую копию. На последнем шаге можно сразу открыть Orange Notes.
- Заметки и локальные модели остаются на месте. Если открыт черновик помощника или есть несохранённые изменения расписания, завершите работу с ними перед обновлением.
- Пользователям v0.2.2 достаточно один раз установить v0.2.3 поверх предыдущей версии. У портативной сборки кнопка «Обновление» открывает страницу выпуска.
