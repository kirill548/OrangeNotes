# Orange Notes 0.1.0: установка и проверка на устройстве

Это инструкция для ручной проверки **готового релизного архива**. Она не является отчётом о проведённой физической проверке. CI проверяет сборку и запуск, но не подтверждает видимость баннера и нажатие кнопок человеком.

## Перед установкой

Скачайте пакет из Releases проекта https://github.com/kirill548/OrangeNotes/releases. Выберите свою ОС и архитектуру: Windows AMD64, Linux x86_64, macOS x86_64 (Intel) или arm64 (Apple Silicon). Для 32-битной Windows сборки нет. Проверьте SHA-256 по файлу контрольных сумм релиза; при несовпадении не запускайте пакет.

Сборки **не имеют production-подписи издателя**; macOS не прошла нотаризацию Apple. Возможны предупреждения SmartScreen и Gatekeeper. Исключение допускается только для проверенного файла этого проекта; не отключайте защиту ОС целиком. Корпоративная политика может запретить исключение.

## Windows

1. Распакуйте `OrangeNotes-Windows-AMD64.zip` целиком в постоянную папку пользователя. Сохраните все файлы рядом с `OrangeNotes.exe`, включая `_internal`; не запускайте EXE прямо из ZIP.
2. Запустите `OrangeNotes.exe` без прав администратора. Если SmartScreen сообщает о неизвестном приложении, после проверки источника и суммы выберите «Подробнее» → «Выполнить в любом случае», если эта кнопка доступна. Предупреждение о вредоносном файле — повод остановиться и проверить файл, а не обходить защиту.
3. Разрешите уведомления Orange Notes в «Параметры» → «Система» → «Уведомления». Для проверки баннера временно выключите «Не беспокоить»/фокусировку. После теста верните свои настройки.
4. Не переносите папку после регистрации фоновой службы: она должна ссылаться на существующий EXE. При переносе откройте приложение из нового расположения и повторно проверьте состояние напоминаний.

## macOS

1. В «Об этом Mac» определите Intel или Apple Silicon. Распакуйте соответствующий `OrangeNotes-Darwin-x86_64.zip` / `OrangeNotes-Darwin-arm64.zip` и перенесите `OrangeNotes.app` в «Программы» до первого запуска.
2. Если Gatekeeper блокирует приложение неизвестного разработчика, после проверки источника откройте «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть» для Orange Notes. Не используйте глобальное отключение Gatekeeper или массовое снятие quarantine.
3. При первом запросе UserNotifications проверьте правильное имя приложения и нажмите «Разрешить». Если диалог уже был показан, проверьте Orange Notes в «Системные настройки» → «Уведомления». Запишите отсутствие повторного диалога отдельно от отказа ОС.
4. Для сценария Denied отключите разрешение в настройках уведомлений и перезапустите приложение. Возврат к Allow выполните там же. Не сбрасывайте разрешения других приложений.

Облачный macOS ранее возвращал Denied; это не подтверждение успешного отображения на физическом Mac. Ad-hoc подпись не заменяет Developer ID и нотаризацию.

## Linux: Debian / Ubuntu (.deb)

В терминале из папки загрузки:

```sh
sudo apt install ./OrangeNotes-Linux-x64.deb
orange-notes
```

Пакет называется `orange-notes`; зависимостями управляет apt. Повышенные права нужны для установки пакета, **само приложение запускайте обычным пользователем**. Пользовательская фоновая служба регистрируется при запуске; при отсутствии user-systemd используется XDG Autostart. Нужны вошедший в систему пользователь, D-Bus и служба уведомлений рабочего стола. Ошибка прав systemd не должна маскироваться успешной установкой fallback.

Удаление пакета: `sudo apt remove orange-notes`. Перед обновлением/удалением сделайте резервную копию через меню приложения; удаление пакета само по себе не является очисткой пользовательских данных и фоновых регистраций.

## Linux: Flatpak

Сначала установите Flatpak средствами своего дистрибутива. Затем из папки загрузки:

```sh
flatpak remote-add --user --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./OrangeNotes-Linux-x86_64.flatpak
flatpak run org.orangenotes.OrangeNotes
```

App ID: `org.orangenotes.OrangeNotes`. Для первой установки runtime 25.08 может потребоваться интернет; локальный `.flatpak` не включает все зависимости. Проверка установки: `flatpak info --user org.orangenotes.OrangeNotes`. Для обновления установите новый локальный пакет той же командой. Удаление приложения: `flatpak uninstall --user org.orangenotes.OrangeNotes` (без `--delete-data`, если данные нужно сохранить).

Flatpak использует XDG Desktop Portal. Действия «Выполнено» и «Отложить» доступны внутри «Требуют внимания»; кнопки портального баннера не обещаются. **Фоновый worker работает, пока приложение живо, в том числе в трее. Полный «Выход» останавливает его; пропущенные события восстанавливаются при следующем открытии.** Автозапуск службы на хосте из sandbox не устанавливается. Не выдавайте широкие filesystem/session-bus permissions для обхода этих ограничений. Подключение внешней локальной ИИ-модели в sandbox не гарантируется.

## Экспресс-проверка Windows и физического Mac

Используйте тестовые заметки без личных данных. Установите напоминания на ближайшие 2–3 минуты. Каждый пункт отметьте PASS / FAIL / BLOCKED и приложите время и снимок экрана без конфиденциального текста.

| Проверка | Ожидаемый результат |
|---|---|
| Первый запуск скачанного архива | Нет консоли, ошибки Qt или запроса прав администратора; значок корректен. Записаны предупреждение SmartScreen/Gatekeeper и выбранное действие. |
| Создание и перезапуск | Заметка, папка, метки и расписание сохраняются после закрытия и открытия. |
| Быстрые действия | Ctrl+K (Cmd+K на Mac) открывает поиск команд; Escape закрывает; выбранная команда выполняется один раз. |
| Заметка только с телом | Для пустого заголовка и текста «Проверить тестовую почту» баннер/список внимания содержит этот текст, а не только «Без названия». |
| Разрешения macOS: Allow | Диалог корректен; баннер виден, событие остаётся в Центре уведомлений до обработки согласно настройкам ОС. Одного ответа API недостаточно для PASS. |
| Разрешения macOS: Denied | Нет зависания или ложного статуса доставки; диагностика показывает запрет, событие доступно в «Требуют внимания». После Allow следующий тест доставляется. |
| Windows: уведомления выключены | Диагностика фиксирует запрет; резервная карточка показывает содержание и количество, «Посмотреть» открывает события. Запрет не считается доставкой ОС. |
| Кнопки напоминания | «Отложить» создаёт новый срок через 10 минут; «Выполнено» обрабатывает событие один раз. Повторяющееся расписание сохраняется. Проверить кнопки как в поддерживаемом нативном баннере, так и в приложении. |
| Окно закрыто в трей | Напоминание приходит; открыть приложение можно из трея. Отдельно проверить полный «Выход» и фактический статус фоновой службы; отсутствие работающей службы — BLOCKED/FAIL, не успех. |
| Перезагрузка / пропущенный срок | Назначить событие, выключить компьютер до срока, включить после него и войти в пользователя. Проверить автозапуск и просроченное событие; не обещается уведомление на выключенном компьютере. |
| 10 одновременных событий | UI отвечает, все разные тексты доступны в «Требуют внимания», нет модальных окон и потери событий. Число баннеров зависит от группировки ОС. |
| Фокусировка / «Не беспокоить» | При скрытом баннере событие доступно в Центре уведомлений/«Требуют внимания». После отключения режима проверить новое событие. |
| Повтор и часовой пояс | Повтор Пн/Ср/Пт 09:00 и 18:30 сохраняется; изменение зоны не создаёт дубликаты. Изменять системную зону только на тестовом устройстве и вернуть исходную. |

Для Flatpak повторите сценарии тела заметки, пропущенного события и 10 событий, учитывая ограничение полного «Выхода». Для Linux без systemd отдельно подтвердите наличие пользовательской XDG Autostart регистрации и доставку после нового входа в сеанс.

## Что сохранить в отчёте

Версия приложения/тег и SHA-256 архива; ОС, архитектура, часовой пояс; тип пакета; режим Allow/Denied/Focus; backend и статус фоновой службы из «Состояние напоминаний»; ожидаемое/фактическое время; PASS/FAIL/BLOCKED каждого сценария; обезличенные снимки и журналы. Различайте «API принял запрос», «баннер виден» и «кнопка обработана». Результаты на Intel и Apple Silicon записываются раздельно.
