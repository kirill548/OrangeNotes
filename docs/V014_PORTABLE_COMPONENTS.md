# Переносимые компоненты ИИ и голосового ввода

Компоненты, которыми управляет Orange Notes, находятся рядом с исполняемым файлом приложения: `ai/` содержит настройки, локальный Ollama и модели, `stt/` — Whisper и модель распознавания речи. В исходном проекте базовой папкой служит корень проекта, а не папка установленного Python.

Пути в настройках сохраняются относительно этой папки. Чтобы перенести настроенное приложение, переносите всю папку вместе с `ai/` и `stt/`. Каталоги с моделями и персональными настройками исключены из Git.

При отсутствии прав записи перенесите распакованное приложение в доступную для записи папку. Загрузка не переключается скрыто на глобальный профиль. Для установленного Linux-пакета, Flatpak, AppImage или защищённого macOS-бандла каталог может быть недоступен для записи; автоматическая установка компонентов тогда недоступна. Используйте распакованную переносимую сборку в собственной папке. На macOS текущий AppDir — `Contents/MacOS`; изменение содержимого подписанного приложения требует отдельного решения поставки и не подтверждено этим изменением.

Существующие внешние модели не перемещаются и не удаляются автоматически. Подключение уже работающего внешнего Ollama сохраняется, но скачивание и удаление через менеджер разрешены только для моделей приложения. Для ручного подключения комплекта сначала поместите его внутрь `ai/`.

Локальное обновление сохраняет содержимое внутренних `ai/` и `stt/`, включая веса, исполняемые файлы и конфигурацию. Каталоги компонентов не должны содержать симлинки или junctions. На время атомарного обновления потребуется дополнительное место для резервной и подготовленной копий.

Хранение заметок и обычных настроек приложения остаётся отдельным вопросом: перенос компонентов ИИ сам по себе не переносит пользовательскую SQLite-базу.

## Нативная проверка macOS

На Mac выполните `python tools/diagnose_whisper_macos.py --output work/macos-whisper-prerequisites.json`. Диагностика проверяет CMake, clang++ через xcrun, macOS SDK и архитектуру Intel/Apple Silicon; она не устанавливает зависимости и не компилирует движок. Флаг `ready_to_build` означает наличие предпосылок, а не подтверждение работы распознавания.

Собирайте приложение и Whisper на соответствующем macOS-хосте. Запуск теста с подменой названия платформы на Windows не является сборкой macOS. На целевой системе после установки необходим отдельный запуск whisper-cli, проверка выбранной многоязычной модели и микрофона, включая разрешение macOS на запись. После изменения подписанного `.app` выполните проверку подписи; успешный тест путей не гарантирует сохранения подписи Apple.

## Сборка Lite и проверка структуры

`python tools/build.py --clean --edition lite` собирает пакет нативно на текущей ОС. Упаковка создаёт пустые каталоги `ai/` и `stt/` рядом с исполняемым файлом; в macOS-бандле это `OrangeNotes.app/Contents/MacOS/`. Пользовательские модели, бинарники и конфигурации из рабочего дерева не включаются автоматически в Lite.

В голосовом мастере доступны base, small Q5_1, base Q5_1 и tiny Q5_1. Компоненты устанавливаются отдельным явным действием после распаковки в доступный для записи каталог. Подробнее: [голосовой ввод](V014_VOICE_INPUT.md), [ручная установка и проверка](INSTALL_AND_SMOKE.md), [архитектуры](PLATFORM_SUPPORT.md).

Финальные статусы CI и ссылки на опубликованные пакеты фиксируются в Release Notes после завершения сборок. Наличие шаблонных каталогов не означает, что Lite содержит настроенную LLM или веса Whisper.
