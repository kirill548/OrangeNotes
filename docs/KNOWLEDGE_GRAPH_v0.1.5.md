# Граф заметок v0.1.5

Ветка разработки: `v0.1.5-dev`. Опубликованный стабильный релиз остаётся v0.1.4.
Вторая фаза: [автономный обход, физическая раскладка и инкрементальный индекс](KNOWLEDGE_GRAPH_PHASE2.md).

## Использование

Введите `[[` в редакторе и выберите заголовок из подсказки. Поддерживаются
`[[Название]]` и `[[Название|Подпись]]`. Ctrl+нажатие на ссылку открывает заметку.
Под текущей заметкой находятся обратные ссылки и упоминания без ссылки.
Кнопка «Граф заметок» открывает интерактивный граф: колесо меняет масштаб,
перетаскивание перемещает вид, нажатие открывает заметку. Активный узел оранжевый.

В параметрах помощника можно выбрать один или два уровня связей от явно
прикреплённых заметок. По умолчанию расширение выключено. Максимум — восемь
дополнительных источников; границы пространства, архива и корзины сохраняются.

## Хранение и индексация

```sql
CREATE TABLE note_links (
  id INTEGER PRIMARY KEY,
  source_id INTEGER NOT NULL REFERENCES notes(id) ON DELETE CASCADE,
  target_id INTEGER REFERENCES notes(id) ON DELETE SET NULL,
  target_title TEXT NOT NULL,
  link_text TEXT NOT NULL,
  context_snippet TEXT NOT NULL
);
CREATE INDEX note_links_source ON note_links(source_id);
CREATE INDEX note_links_target ON note_links(target_id);
```

`source_id` — автор ссылки; `target_id` — найденная заметка. Неразрешённые
ссылки сохраняют `target_title` и NULL в `target_id`. Заголовки сопоставляются
через Unicode casefold и нормализацию пробелов только внутри одного пространства.
При неоднозначном заголовке случайный адресат не выбирается.

Триггеры изменения заметок ставят ID в очередь `note_links_dirty(note_id)`
и сохраняют зависимости старого/нового заголовка. Фоновый индексатор обновляет
изменённые источники и ссылки на изменённые названия пакетами до 128 заметок
в собственной SQLite connection. Запрос также обновляет грязный индекс, поэтому сервис работает
без запущенного GUI. Повторное открытие Store не инвалидирует чистый индекс.

Парсер исключает HTML-атрибуты, script/style, блоки кода, экранированные и
некорректные ссылки. Переименование обновляет ссылки транзакционно, сохраняя
алиасы и не меняя другие пространства. Восстановление базы допускает только
точные определения служебных триггеров и останавливает фоновые обращения.

## Контекст ИИ

Инструменты `get_linked_notes(note_id)` и `get_backlinks(note_id)` имеют строгие
схемы аргументов и read-only исполнитель `CompanionEngine.execute_graph_tool`.
Пространство и разрешённые начальные ID задаёт приложение, а не модель.
Доступны детерминированный обход и явно включаемый автономный выбор инструментов
моделью: максимум три вызова, два уровня и восемь дополнительных источников.
Циклы и дубликаты исключены.
Источники проходят проверку актуальной ревизии и существующие grounding-проверки.

Модель выбирает следующий read-only инструмент через нативный Ollama Tool Calling.
Её промежуточный текст не становится доказательством и не показывается как ответ.
Финальный ответ проходит прежние проверки заземления.

## Ограничения прототипа

- Граф использует ограниченную симуляцию сил с агрегацией отталкивания в сетке;
  для крупных коллекций подписи скрыты, кроме активной заметки.
- Первая индексация и миграция читают все заметки; дальнейшие изменения инкрементальны.
- Неупомянутые связи — буквальные совпадения заголовка, не семантический поиск.
- Ссылки на одинаковые заголовки требуют устранить неоднозначность вручную.
- Автотесты не заменяют интерактивную проверку на реальном рабочем наборе заметок.

## Проверки

`tests/test_knowledge_graph.py` проверяет синтаксис, миграцию, разрешение ссылок,
переименование, циклы, удаления и изоляцию. `tests/test_knowledge_graph_ui.py`
проверяет подсказки, навигацию и активный узел. `tests/test_knowledge_graph_ai.py`
проверяет разрешения, фильтры, ограничение обхода и заземление источников.
Матрица CI: Windows x64, Linux x64, macOS Intel и Apple Silicon.
