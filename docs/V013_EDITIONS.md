# v0.1.3: Lite и Complete — сборка и проверка

> Исторический отчёт этапа разработки. Актуальный статус релиза: [README](../README.md); текущий план: [ROADMAP](../ROADMAP.md). Измерения ниже относятся к указанному в отчёте прогону.


Инфраструктура редакций вошла в v0.1.3. Официальные пакеты выпускаются как Lite; модель по умолчанию Complete Edition не утверждена.

## Сборка

Lite сохраняет прежние имена пакетов и поддержку внешнего Ollama / AI-pack:

```sh
python tools/build.py --clean --edition lite
```

Complete по умолчанию собирается отдельно в dist/complete; имена её архивов, DMG и AppImage имеют суффикс -Complete. Она требует заранее подготовленный комплект для целевой ОС и архитектуры:

```sh
python tools/build.py --clean --edition complete --ai-pack /path/to/verified-pack
```

Комплект содержит bundle_manifest.json (schema_version 1, engine ollama), native runtime в runtime/ollama, установленные модели Ollama в models, сведения license/source/engine_version, platform/architecture, имя model и инвентарь files с size/SHA-256. Проверяются ссылки, полный состав, размеры, хэши и ссылки манифестов моделей на blobs. Пользовательские базы и настройки запрещены даже в заявленном инвентаре.

Read-only seed входит в ресурсы bundled_ai. При первом открытии помощника он устанавливается в пользовательское управляемое хранилище в фоновом потоке. Отмена проверяется при чтении каждого блока весов; повторный запуск после сбоя возобновляет только неизменённый собственный комплект с совпадающим отпечатком. Существующая конфигурация Ollama или AI-pack имеет приоритет. Ошибка установки сохраняет возможность поиска без модели. Lite не скачивает веса автоматически.

## Локальное обновление

```sh
python scripts/deploy_local.py --edition lite --target /path/to/local-install
python scripts/deploy_local.py --edition complete --ai-pack /path/to/verified-pack --target /path/to/local-install
```

Для готового артефакта можно указать --bundle и соответствующую --edition. --dry-run показывает команды; --no-launch устанавливает без запуска. Complete использует отдельный work/deploy-local/complete/dist; Lite сохраняет прежний work/deploy-local/dist.

Приложение нужно закрыть перед обновлением. package заменяется через staging/rollback, остальные файлы сохраняются. Перед запуском проверяются SHA-256 portable notes.db/notes.sqlite3, WAL/SHM и настроек в целевой папке. Пользовательские models/ai_packs вне управляемого исполняемого payload не удаляются. БД и настройки внутри payload блокируют обновление; исключение сделано только для проверенных ресурсов модели Complete.

## Синонимы

В диалоге помощника нажмите «Синонимы» и создайте группу, например: машина, автомобиль. Группы относятся к выбранному личному или рабочему пространству. Они используются только если буквальный поиск ничего не нашёл. ID, номера, пароли и токены не расширяются. При отсутствии FTS5 сохраняется обычный поиск.

## Статус модели

Полный Complete-дистрибутив с утверждённой базовой моделью пока не выпущен. Qwen2.5-1.5B-Instruct Q4_K_M — кандидат, а не подтверждённый победитель. Реальные измерения и ограничения приведены в V013_AI_ENGINE_COMPARISON.md.
