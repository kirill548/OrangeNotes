# Поддерживаемые архитектуры Orange Notes

Целевая матрица релизных сборок использует Python 3.12, Qt 6 / PySide6 и
64-битные процессы. Архитектура проверяется на раннере до тестов и упаковки.

| Платформа | Архитектура | Форматы Lite |
|---|---|---|
| Windows | x64 / AMD64 | `.exe` в standalone-каталоге, `OrangeNotes-Windows-AMD64.zip` |
| Linux | x64 / AMD64 | `.deb`, AppImage, Flatpak |
| macOS Intel | x86_64 | `.app`, `.dmg`, архив бандла |
| macOS Apple Silicon | arm64 | `.app`, `.dmg`, архив бандла |

Windows x86 (32 бита) не входит в текущую целевую матрицу и не получает
релизные пакеты. Это решение о поддержке выбранного стека и его зависимостей,
а не утверждение, что сам Python 3.12 нигде не поддерживает 32-битные системы.
Установка x64-сборки требует 64-битной ОС. Intel и Apple Silicon проверяются
отдельно; успешный прогон одной архитектуры не подтверждает другую.

Полный регрессионный прогон выполняется через `tools/run_cross_platform_qa.py`:
он сохраняет версию Python/SQLite, наличие FTS5 unicode61, фактическую
архитектуру, JUnit, полный журнал и количества Passed/Skipped/Failed.
Пропущенные тесты не учитываются как успешно выполненные.

Для Linux нативные уведомления требуют доступной D-Bus-сессии и демона
уведомлений; виртуальный X11 позволяет проверить интеграцию с Dunst.
Для macOS прохождение обычных тестов на облачном раннере не доказывает показ
баннера Notification Center или взаимодействие пользователя с разрешениями.
Такая проверка требует соответствующего нативного теста и авторизованной
графической сессии; отсутствие условий отмечается отдельно в отчёте.

Lite не включает веса модели. Complete требует отдельно квалифицированный
AI-pack под целевую ОС и архитектуру; результаты Lite не квалифицируют модель.
