# Локальный голосовой ввод — v0.1.4

Голосовой ввод заполняет поле сообщения. Распознанный текст можно исправить перед отправкой. Распознавание не отправляет команду помощнику автоматически и не сохраняет заметку без подтверждения.

## Движок и установка

Используется отдельный локальный `whisper-cli` из whisper.cpp. Адаптер запускает его без оболочки, с русским языком (`-l ru`), отключённым GPU (`-ng`) и двумя CPU-потоками по умолчанию. PyTorch, CUDA и облачный сервис не требуются.

Движок и веса не скачиваются автоматически. Lite-пакет не содержит веса Whisper. Для работы нужны:

- нативный исполняемый `whisper-cli.exe` для Windows или `whisper-cli` для Linux/macOS и его необходимые библиотеки;
- совместимый с этой версией whisper.cpp файл **многоязычной** модели tiny или base, включая поддерживаемый квантованный вариант. Модели с суффиксом `.en` не подходят для русского языка;
- доступный микрофон с разрешением на запись и поддержкой PCM 16 кГц, mono, Int16;
- модуль `PySide6.QtMultimedia` и нативные плагины Qt Multimedia в установленной или упакованной сборке.

Проверяйте происхождение, лицензию и контрольную сумму скачанного движка и весов. Приложение запускает настроенный локальный исполняемый файл; не указывайте случайные программы вместо Whisper. Пути с пробелами и кириллицей передаются отдельными аргументами, без shell.

По умолчанию интеграция ожидает движок и модель в `stt/` внутри каталога пользовательского профиля: `whisper-cli.exe` / `whisper-cli` и `ggml-tiny.bin`. Панель выбора движка и модели пока не реализована: для текущей интеграции используются эти фиксированные пути. Квантованный совместимый файл можно поместить как `ggml-tiny.bin`; имя файла само по себе не подтверждает формат и совместимость весов.

## Запись, отмена и приватность

Кнопка микрофона начинает запись. Повторное нажатие завершает запись и запускает распознавание; отдельная отмена очищает записанный буфер. Статусы показывают запись и обработку. После обработки результат появляется в обычном поле сообщения.

Ограничения: запись до 60 секунд (до 1 920 000 байт PCM), распознавание до 60 секунд, текстовый результат до 65 536 байт. WAV и временные файлы движка создаются в системном временном каталоге и удаляются после завершения, ошибки или отмены распознавания. При аварийном завершении ОС или приложения удаление временных файлов не гарантировано.

Аудио не передаётся по сети. Кнопка отправки работает с уже распознанным текстом по обычным правилам помощника. Отмена распознавания завершает только созданный приложением дочерний процесс движка.

## Недоступный микрофон или движок

Отсутствие Qt Multimedia, микрофона, модели, разрешения на запись или поддерживаемого формата вызывает понятное сообщение; текстовый ввод остаётся доступным. Приложение не подставляет вымышленный результат и не переключается на облачное распознавание. Поддержка иных частот микрофона через ресемплинг пока не реализована.

## Проверки и ограничения подтверждения

`tests/test_stt_platform_contract.py` проверяет переносимые контракты: отсутствующий необязательный движок, пути с кириллицей/пробелами, отказ от запуска процесса при неверном PCM и включение Qt Multimedia в конфигурацию упаковки. Названия платформ в параметрах теста не означают запуск на этих ОС.

Тесты с mock-потоками проверяют логику записи и ошибки, но не подтверждают качество распознавания или работу физического микрофона. В текущем локальном окружении имеется только PySide6 Essentials: Qt Multimedia, движок и модель не установлены. Нативный аудиотест Windows/Linux/macOS и проверка упакованного голосового ввода требуются отдельно. Полная новая матрица Actions должна выполняться на соответствующих ОС; прежние результаты v0.1.3 не доказывают работоспособность нового аудиопайплайна.
