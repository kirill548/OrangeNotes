## AGENT 8 — лингвистический ревизор

В реальном ответе «Кто ты?» из work/user-preview/qwen3-live-small-talk.json найдены:

- «органайзацией»: орфографическая ошибка; правильно «организацией».
- Переход от «тебе» к «вам» внутри одного ответа. Требование: обращаться на «вы» последовательно.
- «управлять календарем и многое другое»: неподтверждённая возможность и расплывчатое обещание. Требование: перечислять только реализованные действия; подготовка черновика не равна сохранению.
- «Пожалуйста, рады помочь!»: множественное число не соответствует одному помощнику. Рекомендуется «Пожалуйста! Обращайтесь».

Эти модельные дефекты зафиксированы; их устранение новым промптом и повторной живой проверкой пока НЕ подтверждено. Формальный прошлый результат 3/3 означает наличие структурно корректного текста, а не лингвистическую готовность.

Исправлено в UI: техническое «NDJSON stream=true» убрано из подсказки подключения; «проверка N мс» уточнено как время проверки соединения; ссылка «Настроить» заменена реальным названием «Настройки ИИ»; анимация «готовит проверенный ответ» теперь не обещает завершённую проверку заранее.

Требования к промпту: простой русский язык, короткие предложения, согласованные падежи, никаких выдуманных инструментов или календаря. Перед подтверждением говорить «подготовил черновик»; после успешной записи — «сохранено». Факты о заметках требуют источников. Ошибка инструмента не должна сопровождаться утверждением об успешном выполнении.

## AGENT 9 — первый запуск

По коду Companion подтверждена конкуренция четырёх быстрых действий, выбора режима, кнопки отправки и панели параметров. Пользователю приходится заранее выбирать технологический режим вместо описания цели. Введение, пространство, прикрепление, статус модели, источники и черновик конкурируют за высоту окна. Даже прокручиваемый черновик ограничен высотой и требует проверки на небольших экранах.

План исправлений:
1. P0: одно поле запроса и одна основная кнопка; маршрутизацию выполнять автоматически. Явно разделять найденные цитаты и ответ.
2. P0: черновик с названием, текстом, датой уведомления и отдельным временем события; кнопка сохранения всегда видна.
3. P1: параметры и технические детали в раскрываемой панели; прикрепление заметок одним действием.
4. P1: краткий статус «Готов / Отвечает / Проверяет источники»; ошибки с понятным следующим шагом.
5. P1: испытать первый запуск, клавиатуру и масштабы 100/150/200% на небольшом экране; не считать чтение кода пользовательским испытанием.

## Этап 2 — реализация

System Prompt v2 подключён к production RAG с прежними правилами цитат и отказа. Живые tool-тесты используют общий языковой контракт, нативный Ollama API и строгий адаптер. Это отдельный тест модели; GUI сохраняет детерминированную маршрутизацию и подтверждение записи.

Выбор технического режима и четыре конкурирующих быстрых действия скрыты. Запрос маршрутизируется автоматически; параметры поиска раскрываются отдельно. Подтверждение «Сохранить в заметки» вынесено из прокручиваемых полей черновика. Состояния сокращены; результаты поиска без генерации явно обозначены.

Запрошенный размер окна 520×480, доступность сохранения проверена при обоих положениях прокрутки. Это не визуальная проверка физического монитора.
