# Orange Notes

Windows: распакуйте весь архив и запустите OrangeNotes.exe. Python устанавливать не нужно. Папка _internal должна оставаться рядом с EXE. Заметки сохраняются отдельно в %LOCALAPPDATA%\OrangeNotes; передавать эту папку другим людям не нужно.

Для локального ИИ распакуйте дополнительный OrangeNotes-AI-Windows-x64.zip в папку с EXE: рядом появится runtime. В приложении откройте «ИИ-помощник» → настройки → проверку модели. Без комплекта доступен обычный поиск по заметкам. Модели работают локально, без аккаунта и API-ключа. Комплект занимает несколько гигабайт; скорость зависит от компьютера.

## Сборки для разных устройств

Один EXE не запускается на всех ОС. Код приложения общий, а пакет собирается на целевой ОС. В `.github/workflows/build.yml` добавлены отдельные задания Windows x64, Linux x64, macOS Intel и Apple Silicon: сборка, проверка запуска и архив для скачивания. Запуск CI требует публикации проекта в репозиторий GitHub; локально на Windows эти другие сборки пока не проверены и не выпущены.

| ОС | Пакет | Статус |
| --- | --- | --- |
| Windows 10 1809+ / 11 x64 | ZIP с OrangeNotes.exe и _internal | Собран и проверен локально |
| Linux x64 | tar.gz с исполняемым OrangeNotes | Подготовлена сборка CI; проверка на Linux необходима |
| macOS 13+ Intel / Apple Silicon | ZIP с OrangeNotes.app, отдельный пакет для каждой архитектуры | Подготовлена сборка CI; проверка на Mac необходима |
| Windows ARM64 | Нужна нативная сборка на ARM64 | В текущей матрице не выпускается |
| Windows x86 (32 бита), Windows 7/8 | Нет поддерживаемых бинарных PySide6 для этого проекта | Требуется отдельный совместимый клиент, текущий EXE не подходит |

Linux: распакуйте tar.gz с сохранением прав доступа и запустите `./OrangeNotes`. Для ярлыка скопируйте исполняемый файл/папку в постоянное место и адаптируйте `Exec`/`Icon` в OrangeNotes.desktop под этот абсолютный путь. Linux-пакет зависит от системных библиотек Qt/X11/OpenGL и не объявляется совместимым со всеми дистрибутивами. macOS: распакуйте архив и перенесите OrangeNotes.app в Applications. Для публичного распространения Mac-пакету дополнительно нужны подпись и notarization; ключи не включены в проект.

В исходниках добавлены независимые службы launchd и systemd --user и адаптеры UserNotifications/libnotify. Они проверены контрактными тестами на Windows, но требуют настоящих испытаний на macOS/Linux. Для Linux нужен современный notify-send и пользовательская D-Bus-сессия; для macOS — .app с Bundle Identifier и условные PyObjC-зависимости. Комплект runtime из Windows-архива ИИ на Mac/Linux использовать нельзя: нужен Ollama для соответствующей ОС.

32-битная совместимость не решается переименованием EXE или выбором x86 в PyInstaller: текущий стек Qt 6/PySide6 требует поддерживаемой 64-битной среды. Безопасный вариант для будущего — отдельный облегчённый интерфейс с сохранением формата SQLite, ограничениями по локальному ИИ и самостоятельными тестами. Переход всего проекта на устаревший Qt 5 только ради x86 не выполнен.

Фоновые напоминания Windows используют задачу OrangeNotes.Reminders, запускаемую при входе пользователя. Не переносите папку приложения после первого запуска без повторного открытия EXE из нового места. Windows должен разрешать системные уведомления; режим «Не беспокоить» влияет на показ баннеров. Выполнение задачи подтверждается пользователем, а не фактом доставки уведомления.

Сборка: Python 3.12, PySide6 6.11.2, PyInstaller 6.22.3. Включённые Qt/PySide библиотеки распространяются по LGPL; их можно заменить в _internal. Лицензии компонентов находятся в комплекте библиотек и отдельном ИИ-комплекте. Приложение пока не подписано сертификатом издателя.

Основание совместимости: https://doc.qt.io/qt-6.11/supported-platforms.html
Сборки по ОС: https://pyinstaller.org/en/stable/operating-mode.html

## Публикация исходников

Корень репозитория — эта папка notes_app, а не outputs или весь рабочий каталог Codex. `.gitignore` исключает базы, журналы, локальные модели, сборки и `.env`. Перед публикацией проверьте список файлов: исключения не удаляют уже отслеживаемые данные. В лицензиях сохранены тексты Python/Qt; условия сторонних моделей находятся отдельно в runtime/licenses. Лицензия собственных исходников пока не выбрана владельцем: наличие Qt LGPL не делает весь проект автоматически LGPL. Не заявляйте открытую лицензию до её выбора.

## Релизный спринт · 6 октября 2026
SQLite использует WAL; фоновые соединения ждут до 5000 мс, GUI — 250 мс с сохранением грязного текста для повторной попытки. В меню добавлено восстановление базы из копии: проверка, остановка принадлежащей базе службы, защитная копия, атомарная замена и откат при ошибке. Подтверждение обязательно.
Пути macOS/Linux стандартизированы через platformdirs; Windows-путь сохранён. Подписи горячих клавиш macOS используют Cmd с нативной семантикой Qt. ИИ имеет 30-секундный бюджет и отдельный UI-таймер; доступные RAM/VRAM проверяются в рабочем потоке, неизвестная VRAM не блокирует запуск.
В CI добавлены DMG и AppImage, полный прогон на Linux/macOS, условные signing/notarization. Настоящие подписи требуют настроенных сертификатов/хранилища ключей; без них сборки явно unsigned. CI ещё не запускался: проект не привязан к GitHub-репозиторию. Intel и Apple Silicon собираются отдельно; Universal не заявляется.

## UTC и резервная индикация
Расписание сохраняет исходный часовой пояс; событие показывается в текущем поясе устройства. В повторяющийся час уведомление создаётся один раз (первое вхождение), отсутствующее время переносится на первую допустимую минуту. Редактор показывает пояс расписания. Старые записи без сведений о поясе при первой миграции привязываются к текущему поясу — проверьте их после переезда.

При отключённых уведомлениях Windows текст задачи доступен в резервной карточке Orange Notes и разделе «Требуют внимания», а при сворачивании — индикация в трее. После полного выхода из интерфейса карточка появится при следующем открытии; событие не теряется и не считается выполненным. Нативная доставка требует разрешения Windows.

## Следующий этап · 8 октября 2026
В ИИ-помощнике появился отдельный переключатель «Искать похожие номера при опечатке».
Он выключен по умолчанию. Похожие идентификаторы показываются только при отсутствии
точного совпадения, обозначаются как предположения и не передаются модели как факты.
Телефоны со скобками, пробелами и дефисами сохраняют точный поиск.

На значке трея отображается количество событий, требующих внимания (до «99+»).
Несколько событий одной заметки учитываются отдельно. Выполненные и отложенные
до будущего времени события исключаются.

В CI добавлены временный импорт сертификатов, удаление ключей после сборки,
проверка настоящего macOS UserNotifications на выделенном компьютере и
экспериментальная сборка Flatpak. Инструкции и переменные: tools/NATIVE_NOTIFICATION_TESTS.md.
Flatpak использует портал уведомлений и не устанавливает службу в системе хозяина.
Для доставки оставьте его работающим; после полного выхода пропущенные события
появятся при следующем запуске. Этот пакет ещё требует проверки на Linux.

## Проверка автозапуска и нативных пакетов
Linux без пользовательского systemd использует XDG Autostart: напоминания
запускаются при входе в рабочий стол без root. Такой автозапуск не перезапускает
службу автоматически после аварии. Flatpak по-прежнему работает в рамках
запущенного приложения. На macOS отказ в разрешении отображается как Denied;
успех notarization подтверждается статусом Accepted перед прикреплением билета.
Локальная проверка Windows: 362 теста (360 PASS, 2 SKIP). Ubuntu WSL проверяет
ядро и упаковщик deb; это не подтверждение нативных баннеров физического рабочего
стола Linux/macOS. Нужны отдельные устройства/раннеры и доступ к Flathub.
