# Orange Notes v0.1.2

Этот релиз ускоряет поиск по заметкам, улучшает работу локального ИИ и добавляет безопасное локальное обновление приложения для разработчиков.

## Новые возможности

- **Полнотекстовый поиск SQLite FTS5.** Индекс с токенизатором `unicode61` быстро отбирает кандидатов перед ранжированием. Индекс обновляется вместе с заметками; при отсутствии FTS5 применяется LIKE-фоллбэк.
- **Безопасный прогрессивный вывод ответов ИИ.** `StreamSegmentValidator` передаёт в интерфейс только проверенные сегменты. Сырые фактические утверждения не показываются до проверки grounding и цитат. Генерация и отмена выполняются асинхронно.
- **Статус ИИ в статус-баре.** Показываются фактически измеренные p50 latency и TTFT, а при доступном провайдере — GPU/VRAM. Недоступные аппаратные метрики обозначаются как N/A, без выдуманных нулей.
- **Управление AI-pack.** Загрузка, отмена, удаление и переключение управляемых моделей без перезапуска приложения. Хранилище изолировано от системного Ollama и сторонних моделей; учтены стандартные системные пути macOS `/var` → `/private/var`.
- **Локальная сборка и обновление.** `python scripts/deploy_local.py` очищает сборочные кэши, собирает PyInstaller-пакет, обновляет управляемую установку с откатом при ошибке и запускает приложение. База SQLite, настройки и скачанные модели сохраняются. Перед обновлением работающий экземпляр нужно закрыть.

## Исправления

- Ресурсы macOS-бандла подготавливаются до этапа подписания, чтобы последующее добавление справки не нарушало подпись.
- Ошибки и частично доступные данные NVML/sysfs обрабатываются без потери остальных корректных аппаратных метрик.
- Усилены проверки путей AI-pack и сценариев сохранения пользовательских данных при обновлении.

## Проверка качества

- Последний локальный Windows-прогон: **611 PASS, 7 SKIP, 0 FAIL**, включая проверки локального обновления.
- Предшествующая матрица CI: Linux x64, macOS Intel и macOS Apple Silicon — **583 PASS, 8 SKIP, 0 FAIL** на каждой платформе; Windows x64 — **588 PASS, 3 SKIP, 0 FAIL**.
- Кроссплатформенные пакеты прошли сборку и проверку запуска. Linux-уведомления проверены через D-Bus/Dunst. После этой матрицы локальный deploy-скрипт дополнительно проверен на Windows; этот результат не заменяет его проверку на физических Linux/macOS-устройствах.
- Реальная Windows-сборка и два локальных обновления сохранили шесть контрольных пользовательских файлов побайтно; SQLite integrity check завершился с результатом `ok`.

## Установка и ограничения

Выберите пакет своей ОС и архитектуры. Основные дистрибутивы не содержат гигабайтные веса моделей: локальный ИИ подключается отдельно через настройки AI-pack.

**Дистрибутивы не подписаны цифровым сертификатом; macOS-нотаризация не выполнялась.** Windows SmartScreen и macOS Gatekeeper могут предупредить о неизвестном издателе. Проверяйте источник загрузки и контрольные суммы. Для доверенной Windows-сборки доступно «Подробнее» → «Выполнить в любом случае»; на macOS — «Открыть всё равно» в системных настройках «Конфиденциальность и безопасность», если эта возможность разрешена политикой устройства. Отключать системную защиту целиком не требуется.

Диалоги разрешений и визуальное появление уведомлений на физическом macOS-десктопе остаются отдельной ручной проверкой. Hosted CI не подтверждает эти пользовательские сценарии. Flatpak не проверялся в указанном прогоне матрицы.

Для обновления сохраняйте пользовательские данные и используйте пакет соответствующей платформы. `deploy_local.py` предназначен для локального цикла разработки и требует сборочного Python-окружения.

Flatpak: напоминания работают, пока приложение запущено; фоновая служба хоста не устанавливается. Сетевой доступ к Ollama и загрузка моделей ограничены песочницей этого пакета.
