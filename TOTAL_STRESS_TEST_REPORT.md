# TOTAL STRESS TEST REPORT — Orange Notes

**Дата:** 17 октября 2026, Asia/Yekaterinburg. **База аудита:** `6663301` (`main`), релиз v0.2.0; исправления ниже находятся в локальном рабочем дереве. Опубликованный IPA и тег не заменялись.

## 1. Вердикт и границы

Проверены пять направлений: Core/нагрузка, безопасность и аварийное восстановление, ресурсы, UI, синхронизация/бэкапы. Работали специализированные агенты с ограничением одновременных исполнителей и отдельной независимой проверкой Sync.

**Подтверждённых CRITICAL-дефектов в выполненных сценариях нет. Это не доказательство отсутствия всех уязвимостей.** Обнаружены 11 воспроизводимых дефектов/недочётов с внесёнными исправлениями и 5 открытых архитектурных/поставочных ограничений. Нельзя объявлять приложение абсолютно стабильным на любых данных, с шифрованием локальной БД или с поддержкой 50k синхронизируемых заметок.

Среда новых проверок — Windows, Python 3.12 / PySide6, Flutter 3.47.7 / Dart 3.13.5. Flutter widget-тесты эмулируют размеры и отступы, но не являются запуском приложения на iPhone/Android. Web-клиент отсутствует. Исторический CI v0.2.0 не засчитывается как свежая кроссплатформенная квалификация этих патчей.

Все нагрузочные БД — синтетические. Пользовательские заметки, сертификаты, модели и установленное приложение не использовались для разрушительных тестов. Крупные временные БД удалены. Watchdog ограничивал длительность дочерних нагрузочных процессов; аппаратной квоты RAM и физического отключения питания не было.

### Что нельзя честно исправить одним патчем

S11–S15 не закрываются фиктивной правкой лимита/PRAGMA или сменой названия пакета. Для них нет готового, проверенного drop-in фикса в этом аудите. План реализации и критерии приёмки:

1. **S11:** версия wire-протокола с согласованием capabilities, проверяемые snapshot/checkpoint, causal frontier и ACK всех доверенных реплик перед сборкой истории; защита revoked/offline устройств, tombstone retention. Приёмка: 50k реплицированных сущностей, переупорядочивание/повторы, restart, отсутствие resurrection, ограниченная память. Простое поднятие MAX_ENTITIES/лимита истории без compaction не предлагается.
2. **S12:** выбрать encrypted SQLite backend для Python и Dart, per-device ключ в OS key store, fail-closed при недоступном ключе, шифрованные backups, copy-and-verify migration с rollback и проверкой незашифрованных WAL/временных файлов. Приёмка: synthetic marker отсутствует во всех файлах после успешной миграции, wrong-key отказ без потери данных. `PRAGMA key` в обычном SQLite не является исправлением.
3. **S13:** keyset-пагинация `(updated_at,id)`, SQL-проекции без `body`, bounded cache и worker для cancellable search; тесты 50k UI без массового создания карточек. Сортировка/selection/autosave должны сохраняться.
4. **S14:** версия JSON-схемы, строгий UTF-8, предел файла/записей, staged validation и одна атомарная транзакция, MD/TXT через plain text без выполнения HTML/JS; тесты broken JSON, duplicate keys, oversized input и rollback. До реализации поддерживаемыми остаются фактические форматы.
5. **S15:** отдельная миграция renderer с golden/widget-тестами вложенных списков, больших таблиц, ссылок, Unicode и hostile HTML. Не смешивать её с текущими security patches.

## 6. Безопасность и восстановление

Три дочерних процесса действительно принудительно завершены в различных стадиях WAL-транзакции: незакоммиченный пакет отсутствует целиком, завершённый commit присутствует целиком, baseline и FK целы, дальнейшая запись возможна. На Windows использован `Popen.kill`/TerminateProcess; это не SIGKILL Linux и не отключение питания. Барьеры fsync/накопителя не квалифицированы аппаратно.

SQL-метасимволы сохраняются как bound text; динамические имена коллекций allow-listed. Script/style извлекаются из RAG как недоверенные данные и не исполняются. Нет NoSQL-хранилища и Web-клиента: NoSQL/XSS браузерный pentest не отмечается пройденным. HTML/Markdown проверки не доказывают безопасность всех внешних renderer/plugin версий.

База и safety backup содержат plaintext synthetic marker: **E2EE/mTLS защищает транспорт, а не локальный файл заметок**. Secure storage используется для ключей/сертификатов, но не для шифрования SQLite.

См. [security evidence](work/total-stress/security/REPORT.md), [backup evidence](work/total-stress/sync-backup-report.md), [crash harness](tools/total_stress_crash.py).

## 9. Sync и Offline-first

Проверены реальные SQLite Outbox/Inbox, reverse order 13 дельт с удалением, повторная доставка/ACK, случайный порядок по 5 seed, атомарное отклонение неверного actor/workspace/equivocation/revoked peer, настоящие loopback TLS-сокеты и отсутствие late ACK после дедлайна. Удалённые записи не воскресают от старых правок. Границы 4096 entities и 8 МиБ history тестируются фактически, а не только чтением констант.

Отсутствие интернета не мешает локальному CRUD. Нестабильный Wi-Fi/мобильная сеть и suspend/resume физических телефонов этим прогоном не моделируются полностью. [Независимый отчёт](work/total-stress/sync-independent.md).

## 10. Что осталось вне live-квалификации

Общая регрессия включает существующие unit/UI/контрактные тесты напоминаний, NLP, AI routing, Tool Calling, STT fallback и управления компонентами. Это не свежий live benchmark Qwen/Ollama, не запись с реального микрофона и не проверка системных баннеров на всех ОС. Нагрузка 50k не прогонялась одновременно с локальной LLM и голосовой моделью; суммарный peak RSS/VRAM такой комбинации не квалифицирован.

Мобильное отсутствие application-level encryption установлено по используемому обычному sqflite backend и отсутствию encrypted migration, а не извлечением файла с физического iPhone. Само шифрование устройства операционной системой зависит от платформы и настроек и не заменяет проверку формата локальной БД.

## 11. Воспроизведение и следующий gate

```powershell
# Из корня, Python 3.12 и Qt/network test dependencies:
python -m pytest tests/ --junitxml=python-final.xml
# Отдельные тяжёлые, только синтетические сценарии:
python tools/total_stress_core.py
python tools/total_stress_large_backup.py
# Из orange_notes_mobile/:
dart format --output=none --set-exit-if-changed lib test
flutter analyze --fatal-infos
flutter test --reporter expanded
```

Крупный Core-run создаёт временные БД и имеет 120-секундный watchdog на дочерний сценарий; на медленной машине это может дать timeout, который нельзя переименовать в PASS. Для Qt без экрана задайте `QT_QPA_PLATFORM=offscreen`; для локальной Windows типографики использовался существующий wrapper `work/v014/run_voice_regression.py` с Segoe UI.

Перед новым релизом: проверить локальные patches/review, запустить свежий cross-platform CI на точном коммите, пересобрать IPA/APK и квалифицировать реальные устройства. Текущий опубликованный v0.2.0 этих новых исправлений ещё не содержит.
