# Orange Notes v0.1.4

## Голосовой ввод и понятный помощник

Локальная диктовка теперь доступна через настройки: выберите микрофон, установите whisper.cpp и модель, запишите текст и проверьте результат перед отправкой. Перенос папки приложения сохраняет компоненты ИИ и STT. База заметок хранится отдельно и переносится отдельно.

- Микрофон выбирается пользователем, выбор сохраняется. Недоступное устройство не заменяется другим без согласия.
- Доступны многоязычные модели Whisper tiny/base/small; small Q5_1 улучшает распознавание по сравнению с компактным tiny на проверенных записях, но точность зависит от звука и устройства.
- Движок и веса устанавливаются внутри `AppDir/stt/` с проверкой SHA256. Управляемые конфигурации, runtime и модели ИИ находятся в `AppDir/ai/`.
- «Четырнадцать ноль ноль» преобразуется в `14:00`, «двенадцать тридцать» — в `12:30`. Поддержаны контекстные формы `14 00` и `12.00`.
- Невалидное время, например `14:60` или `25:00`, требует уточнения. Неоднозначные значения не исправляются наугад; суммы, номера и длительности не превращаются во время.
- Звуковые пометки вроде `[музыка]` не вставляются как речь. Нет микрофона или аудиобиблиотеки — показывается понятное сообщение без падения интерфейса.
- Текст после распознавания доступен для исправления. Напоминание сохраняется только после подтверждения черновика.

## ИИ и интерфейс

- System Prompt v2 задаёт обращение на «Вы», простой русский язык и запрет обещаний несуществующих функций.
- Аргументы инструментов проходят проверку JSON, типов и допустимых полей перед бизнес-логикой.
- В чате оставлено единое поле запроса, технические настройки вынесены отдельно; черновик содержит явные поля и кнопку сохранения.
- Сохранены Ollama, внешние AI-packs, поиск FTS5, привязка заметок, grounding, проверенный сегментный стриминг и изоляция пространств.

## Проверка

- Локальный полный прогон: **1075 PASS, 12 SKIP, 0 FAIL**.
- Дополнительные UI-проверки: **23 PASS**.
- На двух синтезированных русских WAV распознаны `14:00` и `12:00`; пользователь также подтвердил работу на своём микрофоне.
- Пакеты Windows x64, Linux x64, macOS Intel и Apple Silicon публикуются только после успешной матрицы для точного коммита тега. Ссылка на фактический прогон и SHA коммита добавляются в описание релиза при публикации.

## Установка и ограничения

Lite не содержит весов моделей: скачайте компоненты в настройках. Каталог приложения должен быть доступен для записи. Linux AppImage при обычном запуске смонтирован только для чтения: для установки компонентов используйте распакованный tar.gz или извлечённую папку AppImage. macOS хранит компоненты рядом с исполняемым файлом внутри `OrangeNotes.app/Contents/MacOS/`.

Распознавание выполняется локально. Загрузка пакетов требует интернета; заметки и записанная речь не отправляются в облачный STT. Физический микрофон и системные разрешения требуют проверки на устройстве пользователя. Сборки без настроенных сертификатов остаются неподписанными; macOS notarization не заявляется. 32-битные ОС не поддерживаются. Complete Edition с квалифицированной моделью по умолчанию не объявляется.
