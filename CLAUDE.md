# Контекст Orange Notes

Orange Notes — кроссплатформенное приложение для заметок: Desktop (Windows/Linux/macOS), Android, iOS и планируемый Web-клиент. Общий репозиторий содержит исходники и сборочные конфигурации; готовые пакеты разных платформ, включая iOS IPA, хранятся в релизах/CI, а не в git.

Прочитайте [AGENTS.md](AGENTS.md): единые правила архитектуры, форматирования, проверок и публикации. Desktop использует Python/PySide6, мобильный UI — Flutter/Dart, нативные host — Kotlin и Swift/UIKit. SwiftUI/React Native не используются. Web ещё требует реализации и отдельной квалификации; не обещайте готовность всех платформ по факту универсального позиционирования.
